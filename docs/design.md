# Paradox Mods 官网设计拆解

> 对象：`mods.paradoxplaza.com` 的**模组详情页**（产品介绍页）与列表页
> 方法：无头浏览器渲染截图 + 抓取运行时注入样式 + 主样式表统计
> 日期：2026-11-17　站点版本：`2.6.1`　主包哈希：`4bbe624edad1972ff319`

标注约定：**[实测]** = 从 CSS / 内联样式 / DOM 直接读到；**[目测]** = 从截图估算，可用但需自己再量。

---

## 一、整体设计思路（先看这个，比色值重要）

这套设计不是"做一个好看的模组站"，而是**做一套框架去服务十几个游戏**。它的核心手法是三层叠加：

```
第 3 层  内容层    模组自己的封面、描述、截图 —— 作者的东西，平台不干预
第 2 层  游戏主题层  按游戏注入 4 个 CSS 变量（底色 + 主色 + 主色文字 + 半透明主色）
第 1 层  产品框架层  深墨蓝底 + Source Sans Pro + 1202px 容器 + 4 列网格 + 固定组件
```

同一套组件，换第 2 层的 4 个变量，CS2 页是深蓝（#0D2439 / #2C74CE），别的游戏是别的色。**这是整个设计最值得抄的一点**：先用一套中性框架立住，再用变量做品牌化，而不是每个游戏画一套。

设计取向上有五个明确取舍：

1. **信息密度优先于留白。** 详情页是 2:1 双栏，右栏直接是"规格表"（MOD ID / 版本 / 订阅数 / 体积 / 更新时间），像产品说明书而不是营销落地页。
2. **媒体先行。** 首屏几乎被封面大图 + 缩略图胶片条占满，文字从第二屏才开始。
3. **CTA 只有一个。** 全页仅一个填充色按钮（订阅），其余全是描边按钮或纯文字按钮。视觉焦点没有竞争。
4. **克制形状。** 控件 3–4px 圆角，卡片 18px，胶囊 999px。不用大圆角、不堆阴影，分层靠 **1px 描边 + 底色差**。
5. **大写小标签做层级。** `DESCRIPTION` `TAGS` `COLLABORATORS` `CHANGELOG` `MORE ABOUT THIS MOD` —— 小字号 + 字母间距 + 灰蓝色，是整页最强的识别特征，也是最省力的分区手段。

## 二、色彩系统

### 2.1 框架层（[实测]，来源：`<body style>` 与 `main.css`）

| 角色 | 值 | 用途 |
|---|---|---|
| 页面底色 | `#191d25` | body 背景，全站基准 |
| 面板底色 | `#2c2c2c` → 实际观感 `#1f242d` 区间 | 侧栏区块、卡片 |
| 浅底 | `#f6f6f6` | 弹窗、亮色区块 |
| 分隔/描边 | `#42454f`、`#697582` | 1px 线、次级描边 |
| 正文灰 | `#adadad` | 描述文字、次级信息 |
| 强调灰 | `#d0d5da` | 键值对的值 |
| 纯白 | `#fff` | 标题 |

### 2.2 游戏主题层（[实测]，CS2 运行时注入）

```css
--gamePageActiveColor:            rgb(44, 116, 206);   /* #2C74CE */
--gamePageActiveColorTransparent: rgb(44, 116, 206, 40%);
--gamePageActiveTextColor:        rgb(80, 151, 244);   /* #5097F4 */
--gamePageBackgroundColor:        #0D2439;
--gamePageBackgroundColorTransparent: #0D243940;
```

游戏页背景 `#0D2439` 是深海军蓝，比框架底色 `#191d25` 更"有游戏感"。列表页顶部再叠一层游戏键图（CS2 天际线 + 天空渐变）做氛围，往下渐隐到 `#0D2439`。

### 2.3 状态色（[实测]，`main.css`）

| 语义 | 值 |
|---|---|
| 成功 / 已订阅 | `#5abe41`，深阶 `#278600`、`#2d9640` |
| 警示 | `#f2a83b`、`#f5a623` |
| 错误 | `#ef2f2f`、`#fe0542` |
| 辅助蓝灰 | `#697582` |

> **注意**：截图里那个绿色的大按钮是「已订阅」状态色，**不是** CS2 的品牌色。CS2 的品牌色是 `#2C74CE` 蓝。别搞混。

## 三、字体与排版

### 3.1 字体（[实测]）

```css
font-family: SourceSansPro, sans-serif;   /* 全站唯一字体族 */
```

只用一个字体族，不用衬线、不用等宽（代码块除外）。层级完全靠**字号 + 字重 + 大小写 + 颜色**拉开。

### 3.2 层级规范（[目测] 字号，[实测] 样式特征）

| 层级 | 特征 | 说明 |
|---|---|---|
| 模组标题 | ~32px / 700 / 纯白 | 只在右栏出现一次，左栏不重复 |
| 区块大标题（H2） | ~26px / 700 / 纯白 | `Installation` `Features` `Compatibility Management` |
| 区块子标题（H3） | ~18px / 700 / 纯白 | `PDX Mods Integration` |
| 正文 | ~14px / 400 / `#adadad` / 行高 1.6 | 描述段落 |
| **大写小标签** | ~11–12px / 700 / `#697582` / `letter-spacing: 0.08em` / 全大写 | 全站最强识别特征 |
| 键值对的值 | ~13px / 600 / 白或 `#d0d5da` | 右对齐 |

**大写小标签是这套设计的灵魂**，用在所有分区头、所有规格表的键名上。想复刻这个调性，先把这条做对。

### 3.3 描述区排版

- H2 与正文间距明显大于正文行距（[目测] H2 上边距 ~40px，段间 ~16px）。
- 列表用实心圆点 + 左缩进 ~24px，行高同正文。
- 行宽受左栏约束（~740px），**不做全宽排版**，这是可读性的关键。

## 四、栅格与布局

### 4.1 容器（[实测]）

```css
--width-inner-container: 1202px;
```

内容最大宽 1202px，居中。视口 1366px 时左右各留 ~82px。

### 4.3 列表页栅格（[目测]）

- 4 列卡片，栏间距 ~16–20px，卡片宽 ~260px。
- 卡片 = 封面 4:3 + 标题 + 元信息行 + 作者行。
- 右侧 ~250px 固定筛选栏（手风琴）。
- 顶部：标签页（All / By followed creators）+ 计数胶囊（`Mods 28,263`）+ 时间范围下拉。

## 五、组件规范

### 5.1 Header
深色条，高 ~56px。左侧游戏图标（圆角方形，24px）+ 游戏名 + 下拉箭头；进详情页后追加 `›` + 模组名，变成面包屑。右侧登录下拉、语言切换、一组图标按钮。

### 5.2 按钮

| 类型 | 规格 | 用途 |
|---|---|---|
| 填充主按钮 | 高 ~40px，圆角 4px，`#5abe41` / `#2C74CE`，白字 700 | 订阅（全页唯一） |
| 描边按钮 | 1px 描边 `#697582`，透明底，白字，全大写小字 | `SHOW ALL` |
| 图标按钮 | 40×40 圆形或方圆形，描边 | 点赞、分享、展开 |

**一屏内只有一个填充按钮**，这条别破。

### 5.3 规格表（右栏信息表）
这是详情页最有价值的组件：

- 每行 = 左 `大写小标签` + 右 `值右对齐`
- 行间 1px 分隔线（`#42454f` 级别的低对比）
- 行高 ~34px，上下 padding 均匀
- 数值用 tabular 风格，位数对齐（377,499 / 8,198 都带千分位）

### 5.4 标签 Chip
`Code Mod` 这类：1px 描边、圆角 3–4px、内边距 ~6×12、小字号、不上色。**不用彩色标签**，靠文字区分。

### 5.5 折叠列表（CHANGELOG）
每行 = 版本号（白，600）+ 日期（灰，右对齐）+ 展开箭头（灰）。底部一个居中的描边按钮 `SHOW ALL`。

### 5.6 图标网格（MORE ABOUT THIS MOD）
圆形容器 ~40px + 细描边 + 内部 glype，下方小字标签。2–5 列自适应。用统一线框图标，不用彩色 logo 原色。

### 5.7 卡片（列表页）
```
封面 4:3，圆角顶部
标题 2 行截断，白，600
元信息行：订阅图标+数 / 点赞图标+数 / 体积   （灰，小字，图标 14px）
作者行：16px 头像 + 名字（灰）
```
描边 1px + 底色略亮于页面，hover 时描边变亮（不上阴影）。

## 六、形状与间距

| 项 | 值 | 说明 |
|---|---|---|
| 控件圆角 | `3px` / `4px` | [实测] 按钮、输入、chip |
| 卡片圆角 | `18px` | [实测] 媒体卡片 |
| 胶囊 | `999px` | [实测] 计数胶囊、头像 |
| 圆形 | `50%` | [实测] 图标按钮、头像 |
| 描边 | `1px` | 全站唯一边框粗细 |
| 阴影 | 基本不用 | 分层靠底色差 + 描边 |

**间距节奏**（[目测]）：基础单位 8，常用 8 / 16 / 24 / 32 / 40。区块之间 32–40，区块内元素间 8–16。

## 七、交互与状态

- **订阅态**：未订阅 = 蓝色描边/填充；已订阅 = 绿色填充 + 对勾图标。颜色本身就是状态。
- **加载占位**：封面图懒加载期间显示模糊的低分辨率占位，不显示骨架块。
- **筛选手风琴**：默认展开第一组，其余折叠；每项右侧显示匹配数量，降低试错成本。
- **面包屑**：`游戏 › 模组名`，游戏名可点回列表。

---

## 八、要复刻的话，先做这五件事

1. **定死一套中性框架**：`#191d25` 底 + 单一无衬线字体 + 1202px 容器 + 1px 描边分层。别一开始就上品牌色。
2. **把"大写小标签"做成一等公民**：一个 `.eyebrow` 类，全站复用。这一条决定了整套设计的辨识度。
3. **详情页用 740 : 300 双栏**，右栏做成规格表而不是"侧边推荐位"。这是它和营销落地页最大的区别。
4. **全页只留一个填充按钮**，其余降级为描边或文字。
5. **媒体放最上面**：16:9 大图 + 缩略图条，文字能往后放就往后放。

## 九、别照抄的地方

- **Cookie 弹窗**是第三方组件（白底黑字、`#3860be` 蓝、`#68b631` 绿），和这套系统无关，别当参考。
- 列表页首行的模糊图是**懒加载占位**，不是设计意图。
- 它的信息架构偏"平台"（多游戏、多平台、协作作者、依赖关系），做单模组介绍页不需要照搬 `PLATFORMS` / `COLLABORATORS` 这类字段。

## 十、复刻用的最小 CSS 骨架

```css
:root {
  /* 框架层 */
  --bg-page:      #191d25;
  --bg-panel:     #1f242d;
  --line:         #42454f;
  --text-primary: #ffffff;
  --text-body:    #adadad;
  --text-muted:   #697582;

  /* 游戏主题层（换游戏只改这 4 个） */
  --game-bg:      #0D2439;
  --game-accent:  #2C74CE;
  --game-accent-text: #5097F4;
  --game-accent-soft: rgb(44 116 206 / 40%);

  /* 状态 */
  --ok:    #5abe41;
  --warn:  #f2a83b;
  --error: #ef2f2f;

  /* 形状 */
  --r-control: 4px;
  --r-card:    18px;
  --r-pill:    999px;
  --container: 1202px;

  /* 字体 */
  --font: "Source Sans Pro", "Noto Sans SC", sans-serif;
}

.eyebrow {
  font-size: 11px;
  font-weight: 700;
  letter-spacing: 0.08em;
  text-transform: uppercase;
  color: var(--text-muted);
}
```

中文场景**必须**补一个中文回退字体（`Noto Sans SC` / 思源黑体）。Source Sans Pro 没有中文字形，直接套用会掉到系统默认宋体，整个调性就散了。
